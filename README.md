# Amazon India Sales Dashboard

## Project Overview

This project focuses on analyzing Amazon India sales data and developing a management dashboard using Microsoft Excel.

The objective is to provide a clear overview of sales, profitability, product performance, order status, payment methods, fulfilment methods, and geographic performance.

## Tools Used

* Microsoft Excel for the Web
* Excel Formulas
* Data Analysis
* Data Visualization
* GitHub

## Dashboard KPIs

* Total Sales
* Total Profit
* Total Orders
* Total Units Sold
* Average Order Value
* Profit Margin

## Analysis Performed

1. Overall Sales & Profit Performance
2. Category & Product Performance
3. Order Status & Revenue Loss
4. Payment & Fulfilment Performance
5. Geographic Performance

## Key Business Insights

* Electronics & Mobiles is the leading sales category.
* UPI is the leading payment method.
* Maharashtra generates the highest sales among the states.
* The analysis identifies returned and cancelled orders for further business investigation.

## Project Deliverables

* Excel Dashboard
* Monthly Sales Analysis
* Category & Product Analysis
* Order Status Analysis
* Payment & Fulfilment Analysis
* Geographic Analysis
